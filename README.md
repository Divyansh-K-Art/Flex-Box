## ✦ Overview

**Flexbox Layout** is a clean, beginner-friendly web page built with **HTML5 and CSS3**.

The project demonstrates how **CSS Flexbox** can be used to create a structured webpage containing a header, footer, left sidebar, right content area, and nested sections.

## ✦ Design

The project follows a simple structured layout:

**Header → Main Content → Footer**

The main content is divided into:

**Left Section + Right Section**

The right section is further divided into:

**Top Section + Bottom Section**

And the bottom section contains:

**Bottom Left + Bottom Right**

This nested structure demonstrates how multiple Flexbox containers can work together to create a webpage layout.
